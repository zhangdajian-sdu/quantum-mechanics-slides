# 量子力学 · 课程课件（Quantum Mechanics Lecture Slides）

**中文** | [English](README.en.md)

主讲：**张大剑**（山东大学 / Shandong University）

全套本科量子力学课程课件，共 **10 章 58 节**，每节一个独立 16:9 PPT，按「现象引入 → 教材推导 → 案例回扣 → 小结与练习」的统一结构组织。

**在线浏览与下载（课程主页）**：https://zhangdajian-sdu.github.io/quantum-mechanics-slides/

- 主页上每节课件支持**在线翻页查看**（无需下载，支持键盘翻页与手机滑动）
- 也可直接下载对应 `.pptx` 文件

## 目录结构

```
slides/
  ch1/   量子力学产生的历史背景（5 节）
  ch2/   波函数与薛定谔方程（5 节）
  ch3/   一维定态问题（5 节）
  ch4/   力学量与算符（9 节）
  ch5/   表象（4 节）

  ch7/   近似方法（8 节）
  ch8/   自旋（6 节）
  ch9/   全同粒子体系（4 节）
  ch10/  散射（6 节）
docs/    GitHub Pages 课程主页与在线查看器源码
```

每节目录内含：

- `chN-sM.pptx` —— 课件本体
- `chN-sM.make_figures.py` —— 全部插图生成脚本（Python + matplotlib，可重复运行复现全部图）
